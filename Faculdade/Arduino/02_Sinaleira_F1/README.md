# Sinaleira de Largada Fórmula 1 - Arduino

Projeto desenvolvido a partir dos conhecimentos aprendidos em aula sobre controle de LEDs.

A ideia foi evoluir o conceito básico de ligar e desligar LEDs, criando uma simulação de uma sinaleira de largada da Fórmula 1.

## Tecnologias

- Arduino Uno
- Linguagem C++
- Tinkercad

## Conceitos utilizados

- pinMode()
- digitalWrite()
- delay()
- Controle de LEDs
